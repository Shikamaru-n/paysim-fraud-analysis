# Datasets

The source data for this project is one CSV file. It is not stored in this repository,
because it is about 470 MB. Download it and place it in this folder before running anything.

## Where to get it

Kaggle: [Synthetic Financial Datasets For Fraud Detection](https://www.kaggle.com/datasets/ealaxi/paysim1)
(the PaySim dataset, published by Edgar Lopez-Rojas). A free Kaggle account is needed to
download it.

## What the scripts expect

| Item | Value |
|---|---|
| File name | `PS_20174392719_1491204439457_log.csv` |
| Location | this folder (`datasets/`) |
| Size | 493,534,783 bytes |
| Lines | 6,362,621 (one header line and 6,362,620 data lines) |
| Columns | 11 |
| Line endings | LF only, with no carriage returns |

Keep the file name as it is. If you rename it, change the name in the two places listed below.

The line endings matter. `BULK INSERT` expects CRLF by default, so the bronze load passes
`ROWTERMINATOR = '0x0a'`. See [docs/row_terminator_note.md](../docs/row_terminator_note.md).
If your download tool converts the line endings, the load will fail.

## The file path in the scripts

The full path to the CSV is written into two scripts. Change it in both to match where the
file is on your machine:

- `scripts/bronze/proc_load_bronze.sql`
- `tests/reconciliation_checks.sql`

## Citation

The dataset's authors ask that this paper is cited:

> E. A. Lopez-Rojas, A. Elmir, and S. Axelsson. "PaySim: A financial mobile money simulator
> for fraud detection". In: The 28th European Modeling and Simulation Symposium-EMSS,
> Larnaca, Cyprus. 2016

PaySim is synthetic data. It was generated by a simulator and does not describe real
customers.

## Why the file is not in the repository

`.gitignore` excludes everything in this folder except this README, and excludes every
`.csv` file anywhere in the project.
